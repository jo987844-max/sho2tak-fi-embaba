# شقتك في إمبابة — نسخة مجانية بدون Firebase

هذه النسخة تعمل مباشرة من المتصفح ولا تحتاج Firebase أو Firestore.
- لوحة الإدارة: admin.html
- كلمة المرور الافتراضية: 1234
- إضافة/تعديل/حذف العقارات والصور تلقائيًا.

مهم: هذه النسخة تحفظ البيانات داخل نفس المتصفح والجهاز (localStorage)، لذلك ليست قاعدة بيانات مشتركة بين أجهزة الزوار. إذا أردت أن تظهر الإعلانات لكل الزوار من أي جهاز، يلزم ربط خدمة خلفية مجانية مثل Firebase أو Supabase مرة واحدة.
